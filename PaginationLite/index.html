Pagination Lite

docx → paginated print preview → PDF via your browser's print dialog. Everything runs locally; the manuscript never leaves this machine.

1. Manuscript

Upload the .docx. Paragraph styles Heading 1 / Heading 2 are treated as titles; centered inline images get their own layout rule; everything else is body text.

2. Style Panel

Auto-populated from what was detected in the manuscript. Edit freely.

Upload a .docx to detect paragraph types.

3. Page Setup

Trim size and margins. Inner/outer mirror between left and right pages via @page :left / :right.

Inner = the spine-side edge (left edge of right-hand pages, right edge of left-hand pages). IngramSpark's minimum gutter grows with page count — check their spec sheet once the final page count is known.

in, added evenly to page dimensions (simplified — off by default; this manuscript's inline diagrams likely don't need it)

4. Preview / Export

Opens the paginated book layout in a new tab. Page count, the even/odd-page warning, and the Export button (gated on fonts finishing download) all live in that tab.

Upload a manuscript first.

In Chrome's print dialog: destination "Save as PDF", Paper size set to match your trim size exactly (Chrome offers a "Manage custom sizes…" option), Margins "None", Scale 100%, and headers/footers off — otherwise Chrome may scale or crop the page instead of exporting it at true size.

Scope note: this tool produces an RGB PDF via the browser's native print-to-PDF. IngramSpark's file checker may or may not accept an RGB interior with black text + grayscale diagrams — untested until a real export is run through it. If it's rejected, the fix is a one-time Ghostscript CMYK/PDF-X-1a conversion pass on the exported file; that's a separate script, not something this tool does. This tool also does not upload, store, or transmit the manuscript anywhere — conversion and pagination happen entirely in your browser tab.
